# Teagar Cozinha

Cardapio online responsivo da Teagar Company, construido com HTML, CSS e JavaScript sem dependencias de runtime.

## Desenvolvimento

```bash
npm run check
npm run build
```

Abra `index.html` diretamente ou use qualquer servidor HTTP estatico.

## Publicacao

O workflow em `.github/workflows/pages.yml` publica a branch `main` no GitHub Pages.
